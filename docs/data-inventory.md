# Data inventory (PII and sensitive data)

| Table.column                         | Data                                                           | Classification                                              | Retention / notes                                                                                            |
| ------------------------------------ | -------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `users.email`, `users.name`          | Person's work email and name                                   | PII                                                         | Kept while the identity exists; global (not tenant-scoped), visible to a tenant only for its members (RLS)   |
| `users.entra_oid`                    | IdP subject id                                                 | Pseudonymous identifier                                     | Same as above                                                                                                |
| `users.last_login_at`                | Timestamp                                                      | Usage data                                                  | Overwritten on login                                                                                         |
| `memberships`                        | Who belongs to which tenant, with role                         | Access control                                              | Deleted on removal (audited)                                                                                 |
| `invitations.email`                  | Invitee email                                                  | PII                                                         | Single use; expires after 7 days; token stored only as SHA-256                                               |
| `sessions.ip`, `sessions.user_agent` | Network metadata per refresh token                             | PII (IP)                                                    | Revoked on logout/rotation; purge rows older than refresh TTL + 30 days (job TODO)                           |
| `audit_log.ip`, `actor_id`, `diff`   | Who did what, from where                                       | Security log, PII (IP)                                      | Append-only; keep per client policy (HIPAA: 6 years). Diffs are redacted for token/secret/password/hash keys |
| `resources.body`, `files` blobs      | Tenant content                                                 | Customer data (may contain PHI if the client puts it there) | Tenant-owned; deleted with the tenant (cascade + blob prefix delete)                                         |
| `integrations.config`                | Partner endpoints and usernames                                | Configuration                                               | Never secrets; `secret_ref` points at Key Vault                                                              |
| Key Vault secrets                    | DB passwords, JWT key, OIDC client secret, partner credentials | Secret                                                      | Never in env files, images or Terraform-managed values (for human-owned secrets)                             |
| App Insights / Log Analytics         | Request traces with tenant id, request logs                    | Operational, PII (IP)                                       | 30 days dev / 90 days prod; credentials redacted at source                                                   |

**Data subject requests:** delete the user's memberships in each tenant (audited). The `users`
row and audit history are retained or pseudonymised per the client's regime.
